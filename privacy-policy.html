1. Operator dan kontak

Situs ini tersedia di dafenka.com. Nama yang tampil adalah Dafenka Rythan; identitas hukum operator/pengendali data belum dipastikan: [nama individu atau badan]. Kontak publik saat ini adalah hai@dafenka.com; konfirmasikan apakah alamat ini menjadi kanal resmi permintaan privasi.

2. Informasi yang diproses

  • Penyimpanan browser (Web Storage). Kode menyimpan pilihan bahasa, tema, gerakan, posisi audio, sebagian status antarmuka, dan penanda kunjungan di localStorage. sessionStorage dipakai untuk variasi tampilan dan status animasi selama sesi tab. Kode preferensi ini tidak mengirim nilainya ke server. Web Storage berbeda dari HTTP cookie.
  • Buku tamu. Nama opsional; pesan wajib. Formulir membatasi nama hingga 32 karakter dan pesan hingga 160. Jika API bersama tidak aktif saat halaman memulai, kiriman disimpan di browser pengirim. Jika API aktif, nama, pesan, dan waktu kiriman dikirim ke backend dan dapat dibaca pengunjung situs lain. Kode API menyimpan paling banyak 500 kiriman terbaru; ini batas jumlah, bukan janji masa retensi. Kode tidak menetapkan kedaluwarsa otomatis untuk daftar kiriman.
  • Pencegahan spam buku tamu. Saat API bersama aktif, server memakai nilai pertama pada header X-Forwarded-For sebagai kunci pembatasan laju, atau anon bila nilainya kosong. Kunci itu diberi TTL 30 detik; IP tidak ditambahkan ke isi kiriman buku tamu. Apakah platform memvalidasi header atau mencatat IP/permintaan pada log, dan berapa lama, belum diketahui.
  • Lokasi. Hanya setelah Anda menekan tombol untuk menghitung jarak, browser dapat meminta izin lokasi. Kode menghitung jarak ke Bogor di perangkat Anda; fitur ini tidak mengirim koordinat ke endpoint situs atau menyimpannya. Browser/perangkat dapat memproses lokasi sesuai pengaturannya.
  • Pemutar Spotify. Iframe tidak dibuat sampai Anda memilih “Muat pemutar Spotify”. Memilih “Jangan muat” mencegah iframe dibuat pada tampilan halaman itu. Pilihan muat/tolak tidak disimpan untuk kunjungan berikutnya. Setelah dimuat, Spotify dan penyedia terkaitnya dapat memakai cookie/teknologi serupa serta memproses informasi penggunaan menurut kebijakan mereka. Lihat Ketentuan Spotify Embed, Kebijakan Privasi Spotify, dan Kebijakan Cookie Spotify.
  • Font dan pustaka eksternal. Halaman meminta font Google Fonts dan pustaka animasi Lenis dari jsDelivr saat dimuat. Permintaan tersebut dapat menyertakan informasi teknis seperti alamat IP dan informasi browser, bergantung pada request dan konfigurasi penyedia. Pemilik mengonfirmasi tidak ada analytics atau cookie pihak ketiga lain selain yang mungkin digunakan melalui Spotify; pemeriksaan kode juga tidak menemukan tag analytics/pixel atau penulisan cookie oleh halaman. Baca Kebijakan Privasi Google dan Kebijakan Privasi jsDelivr. Kebijakan jsDelivr menjelaskan data penggunaan CDN dan penyedia CDN yang membantu melayani permintaan.
  • Tautan keluar. Tautan media sosial dan situs lain tidak sama dengan embed otomatis; jika Anda membukanya, layanan tujuan memproses data menurut kebijakannya sendiri.

Status: local review draft. Effective date: [complete after approval].

1. Operator and contact

This site is available at dafenka.com. The displayed name is Dafenka Rythan; the operator/data controller’s legal identity has not been confirmed: [individual or legal entity]. The public contact currently shown is hai@dafenka.com; confirm whether it is the official privacy-request channel.

2. Information processed

  • Browser storage (Web Storage). The code stores language, theme, motion, audio position, some interface states, and a visit marker in localStorage. sessionStorage is used for a display variation and animation state during the tab session. This preference code does not send those values to the server. Web Storage is different from an HTTP cookie.
  • Guestbook. A name is optional; a message is required. The form limits names to 32 characters and messages to 160. If the shared API is inactive when the page initializes, an entry is stored in the submitting browser. If the API is active, the name, message, and submission time are sent to the backend and can be read by other site visitors. The API keeps at most the 500 most recent entries; this is a count limit, not a retention promise. The code sets no automatic expiry for the entry list.
  • Guestbook abuse prevention. When the shared API is active, the server uses the first value in the X-Forwarded-For header as a rate-limit key, or anon if empty. That key has a 30-second TTL; the IP is not added to the guestbook entry. Whether the platform validates the header or logs IPs/requests, and for how long, is unknown.
  • Location. Only after you press the distance button may your browser ask for location permission. The code calculates distance to Bogor on your device; this feature does not send coordinates to a site endpoint or store them. Your browser/device may process location under its own settings.
  • Spotify player. The iframe is not created until you choose “Load Spotify player.” Choosing “Don’t load” prevents the iframe from being created for that page view. The load/decline choice is not saved for later visits. Once loaded, Spotify and related providers may use cookies or similar technologies and process usage information under their policies. See Spotify’s Embed Terms, Privacy Policy, and Cookie Policy.
  • External fonts and library. The page requests Google Fonts and the Lenis animation library from jsDelivr when it loads. Those requests may include technical information such as IP address and browser information, depending on the request and provider configuration. The owner confirms that the site uses no analytics or other third-party cookies beyond those that Spotify may use; the code review also found no analytics/pixel tags or page-written cookies. Read Google’s Privacy Policy and jsDelivr’s Privacy Policy. jsDelivr’s policy describes CDN usage data and the CDN providers that help serve requests.
  • Outbound links. Social-media and other links are not automatic embeds; if you open one, the destination service processes your data under its own policy.

3. Sharing and service providers

Guestbook entries are sent to a backend only when the shared API is active. The repository refers to Vercel serverless functions and the Vercel KV/Upstash package, but the production provider, data location, subprocessors, and logging practices must be confirmed: [name the active providers, country/region, and applicable policy links]. localStorage remains until you clear this site’s browser data; sessionStorage generally ends with the tab session.
